## Time

The function $$time is used to convert a time specified in string format into the 'Time' data type.This is mainly required when a string contains a time on which manipulations are to be performed treating it as a time format eg: filtering the data based on the time comparison.TDL allows Addition or substraction of a number to a time type field and in turn it will return a time type field.

### Meta

- **Total Mandatory Parameters**: 1
