## HasTCPs

This function verifies whether the file with extension is .tcp is activated in Tally.ini file or not. This function does not accept any parameter and returns a logical value. If .TCP file is available it will return a logical value Yes otherwise returns a logical value No.

### Meta

- **Total Parameters**: 0
- **Total Mandatory Parameters**: 0
- **Category**: Module
- **Execution Mode**: Client
- **Return Type**: Logical

### Parameters

_No parameters._
