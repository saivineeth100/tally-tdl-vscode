## DateTime

The function $$datetime is used to convert a datetime specified in string format into the 'Date Time' data type.This is mainly required when a string contains a datetime on which manipulations are to be performed treating it as a date time format eg: filtering the data based on the date time comparison.TDL allows Addition or substraction of a number to a date time type field and in turn it will return a date time type field.
